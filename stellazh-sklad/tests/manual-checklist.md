# Ручная проверка интерфейса

Автоматические тесты (`npm test`) проверяют логику. Интерфейс нужно пройти руками в браузере и заполнить
столбцы «Фактически» и «Статус» своими результатами (дата, браузер — внизу).

| ID | Сценарий | Ожидаемо |
|---|---|---|
| M-01 | Остатки → «Новая позиция», заполнить поля, «Добавить позицию» | Позиция в таблице, остаток 0, статус «Нет на складе» | 
| M-02 | Документы → черновик ПН-0003 → «Провести документ» | Статус «Проведён», остатки выросли, записи в журнале | 
| M-03 | Новый акт списания, позиция «Стрейч-плёнка», количество 500 | Строка подсвечена красным, «не хватает 482» | 
| M-04 | Нажать «Провести документ» с превышением | Документ не проведён, список ошибок, остатки прежние | 
| M-05 | Провести списание, после которого остаток ниже минимума | Жёлтый блок «ниже минимума» | 
| M-06 | Проведённый документ → «Редактировать» (подтвердить) → изменить количество → провести | Остатки пересчитаны, номер документа прежний | 
| M-07 | Контрагенты → «Новый покупатель» с БИН из 3 цифр | Сообщение «БИН/ИИН — ровно 12 цифр» | 
| M-08 | Обновить страницу (F5) | Данные сохранились |
